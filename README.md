# 润泽说 道可道之黄帝阴符经

> 三章通释（v1.0.0）：不与天争机，不与物争盗。

《黄帝阴符经》三百余字，三章三十一句。本书以唐李筌三百字本为底，参敦煌残卷，逐句解读：原句｜字源｜深解｜体系联动｜和合对照｜跨典互参。

## 三辨

1. **五贼**：体为五行，用在相克裁制；相生为德，相克为贼；害中含恩，裁而后成。
2. **三盗**：天地、万物、人互为盗，循环取资，非掠夺；取而有还，用而有时。
3. **杀机**：天地杀机是代谢，人之杀机是私意造对立；杀是革故，非屠戮。

> 识天地自然之杀机，不启一己私欲之杀机；知万物互资之盗机，不生强取掠夺之盗心。
