经旨：三辨

五贼之辨。五贼以五行为体，以相克裁制为用。相生为德，相克为贼；贼不是五行全体，更不是五种邪祟。克非纯害，害中含恩，裁而后成——无克则生而泛滥。

三盗之辨。天地、万物、人互为盗，是循环取资，不是掠夺：天地养万物，万物养人，人复归天地。取而有还，用而有时，故曰「三盗既宜，三才既安」。

杀机之辨。天之杀机是寒暑代谢，地之杀机是蛰起应时，皆自然；唯「人发杀机」是以私意造对立，故全篇警戒。杀是革故，非屠戮。

识天地自然之杀机，不启一己私欲之杀机；
知万物互资之盗机，不生强取掠夺之盗心。

体例：一句六段

每句原文独立成组：字源溯源、逐句深解、体系联动、和合对照、跨典互参。合则见理，分则见句。全书三十一组，不混作通篇泛论。

底本：唐李筌三百字本，参敦煌残卷。三章旧题从通行本，不改经文。配图二：五贼制化循环、三盗三才循环。

和合之辨仍是判尺：凡有一「我要如何」在前，即落合；凡只一「时至而应」在後，即近和。
